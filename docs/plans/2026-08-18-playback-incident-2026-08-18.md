# Playback incident evidence

Tanggal: 2026-08-18

## Bukti production

- Di `https://music.malawalipayment.web.id/`, klik track `Sedia Aku Sebelum Hujan` versi Idgitaf.
- Setelah menunggu resolver, browser console membaca satu elemen audio dengan `paused=false`, `readyState=4`, `networkState=1`, `currentTime=19.208`, `duration=230.130`, dan `error=null`. Ini membuktikan native audio/proxy dapat bermain untuk track tersebut.
- URL audio yang dipakai berasal dari CDN SaveTube `cdn401`; URL tidak disalin ke laporan demi menghindari kebocoran signed URL.
- Klik Next mengubah URL route ke `/play/USrkBUWY3NI` dan metadata menjadi `Sedia Aku Sebelum Hujan — Helena`, tetapi elemen audio tetap memiliki source lama, `readyState=0`, `paused=true`, dan `currentTime=0`.
- Probe production POST `/api/ytplay` untuk `USrkBUWY3NI` menghasilkan HTTP 503 dalam 1,48 detik dengan `code=UPSTREAM_CIRCUIT_OPEN`.
- IFrame YouTube diuji dari origin production dengan `origin=https://music.malawalipayment.web.id`; hasil visual/playing perlu diverifikasi setelah iframe selesai dimuat. Direct embed sebelumnya tanpa origin menghasilkan Error 153.

## Hipotesis utama

1. SaveTube memang unavailable untuk track kedua pada instance production.
2. Frontend mengganti metadata/route sebelum audio resolver selesai, lalu mempertahankan source audio lama ketika resolver baru gagal. Ini dapat menjelaskan mengapa judul berubah tetapi source audio tidak.
3. Circuit breaker mempercepat error tetapi state memory Vercel tidak global; status `UPSTREAM_CIRCUIT_OPEN` dapat berbeda antar instance.

## Acceptance criteria berikutnya

- Jika resolver gagal, `audio.src` harus dikosongkan atau tetap terikat ke track lama tanpa menampilkan track baru sebagai playing.
- Tidak boleh ada mismatch antara `S.ct`, judul yang tampil, dan audio source.
- Jalur recovery harus diuji dari origin production, bukan hanya direct iframe URL.

## Tambahan bukti browser

- IFrame YouTube yang dibuat dari origin MalaMusic dengan `origin=https://music.malawalipayment.web.id` tetap menampilkan `Video player configuration error`, `Error 153`, dan tombol Watch video on YouTube. Jalur IFrame tidak dapat dianggap recovery 100% pada browser test ini.
- Setelah iframe dihapus, player native MalaMusic tetap berada pada state loading/paused untuk track `USrkBUWY3NI`.
- Kesimpulan sementara: satu track tertentu dapat diputar karena URL CDN sudah tersedia/cache, tetapi jalur resolver baru masih gagal untuk track lain; YouTube IFrame resmi juga tidak menjadi fallback universal dalam kondisi pengujian ini.

## Bukti fallback resmi

- IFrame `https://www.youtube-nocookie.com/embed/5QMsYmJYUlQ?enablejsapi=1&origin=https://music.malawalipayment.web.id&playsinline=1` dengan `referrerPolicy=strict-origin-when-cross-origin` berhasil memuat thumbnail/video player dari origin production.
- Setelah tombol Play pada iframe diklik, browser menampilkan video `Kita Usahakan Lagi` dengan durasi 3:53 dan kontrol YouTube aktif. Ini membuktikan jalur resmi dapat dipakai sebagai recovery interaktif, tetapi bukan native `<audio>` atau offline binary.
- Versi iframe tanpa origin sebelumnya menghasilkan Error 153; parameter `origin` dan `youtube-nocookie.com` diperlukan dalam pengujian ini.
